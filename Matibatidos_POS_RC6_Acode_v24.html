Estado del respaldo
Aún no se ha creado un respaldo desde este navegador.

☁️ Respaldo externo

Conecta el sistema a un servicio externo mediante una URL HTTPS. La opción incluida permite guardar el respaldo completo en Google Drive mediante Apps Script. El sistema enviará una copia completa en formato JSON.

☁️ Conectar con Google Drive
Puedes usar el backend de Google Apps Script que acompaña esta versión. Después de publicarlo como aplicación web, pega aquí su URL HTTPS y guarda la configuración.
  1. Abre script.google.com y crea un proyecto.
  2. Copia el archivo Matibatidos_Backup_GoogleDrive.gs que acompaña este sistema.
  3. Publica el proyecto como Aplicación web, ejecutándolo como tú y permitiendo acceso según tu configuración.
  4. Copia la URL HTTPS publicada y pégala en “URL de respaldo”.
  5. Pulsa Probar respaldo externo.

Todo se guarda localmente en este navegador. Usa Respaldo para exportar una copia completa (ventas, productos, inventario, compras, clientes, gastos, caja, usuarios y actividad) antes de cambiar de dispositivo.
